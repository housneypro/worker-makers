# worker-makers

AI 작업자 구성과 작업 지침을 정리하기 위한 저장소입니다. 현재는 저장소 기본 설정과 문서만 준비되어 있습니다.

## 구성

- `AGENTS.md`: 이 저장소에서 작업하는 AI 에이전트의 지침
- `.gitignore`: Git 추적 제외 규칙
- `LICENSE`: MIT 라이선스

## 시작하기

```powershell
git clone https://github.com/housneypro/worker-makers.git
cd worker-makers
```

## 커밋 작성자 설정

새 환경에서는 다음 명령으로 이 저장소에만 작성자를 설정합니다.

```powershell
git config --local user.name housneypro
git config --local user.email housneypro@gmail.com
```

커밋 작성자 설정과 GitHub 로그인 계정은 별개입니다.

## 작업 및 검증

작업 전 `AGENTS.md`를 확인합니다. 아직 애플리케이션 코드나 빌드·테스트 명령은 없습니다. 실행 가능한 코드가 추가되면 설치, 실행, 검증 방법을 이 문서에 함께 기록합니다.
